# Руководство пользователя: лидерборд игрового рейтинга

Сервис показывает таблицу лидеров игры: кто сколько набрал очков в текущем сезоне и на каком месте находится. Руководство рассчитано на игрока и на разработчика клиента (сайт, мобильное приложение), которому нужно показать рейтинг.

## Как получить доступ

Сервис работает как HTTP API. Для знакомства проще всего запустить учебный сервер и открыть интерфейс Swagger UI:

1. Запустите сервер: `python src/server.py`.
2. Откройте в браузере `http://localhost:8000/docs`. Там все запросы можно выполнить кнопкой «Try it out».

Запросы на чтение (топ, игрок, сезон) доступны всем без ключей.

## Как игрок получает очки

- Очки начисляет **игровой сервер** после матча или другого события. Сам игрок их не отправляет, поэтому накрутить рейтинг клиентом нельзя.
- За одну операцию начисляется от **1 до 10 000** очков.
- Очки только **прибавляются**: уменьшить их нельзя, даже при проигрыше.
- Очки суммируются в рамках **сезона**. Когда сезон сбрасывается, у всех игроков снова 0, а новый сезон начинается с пустой таблицы.
- Игрок появляется в таблице после первого начисления очков. Пока очков нет, найти его по нику нельзя.

Ник состоит из 3–20 символов: латиница, цифры, «_» и «-». Регистр не важен: `NeoKnight` и `neoknight` — один и тот же игрок.

## Как смотреть топ

Топ-10 по умолчанию:

```bash
curl "http://localhost:8000/leaderboard"
```

Топ-3:

```bash
curl "http://localhost:8000/leaderboard?k=3"
```

(В PowerShell вместо `curl` используйте `curl.exe`.) Ответ содержит номер сезона и список игроков:

```json
{
  "season": 1,
  "entries": [
    {"rank": 1, "nickname": "NeoKnight", "score": 1250},
    {"rank": 2, "nickname": "Alice", "score": 900}
  ]
}
```

Параметр `k` — от 1 до 100. Игроки идут по убыванию очков. Если очки равны, выше стоит тот, кто набрал их **раньше**.

## Как найти свою позицию

```bash
curl "http://localhost:8000/players/NeoKnight"
```

В ответе будут ваши очки и место в таблице (`rank`). Информация о текущем сезоне и количестве игроков — по адресу `/season`.

## Сброс сезона

Сброс обнуляет таблицу и начинает новый сезон. Его может выполнить только администратор, и он необратим для текущей таблицы. Результаты завершённого сезона сохраняются в архиве, поэтому достижения не пропадают бесследно.

## Частые вопросы и ошибки

| Ситуация | Причина и что делать |
|----------|----------------------|
| `404 player not found` | В этом сезоне у игрока ещё не было начислений, либо сезон только что сбросили. Игрок появится после первого начисления очков |
| `400 invalid nickname` | Ник не подходит под правила: 3–20 символов, только латиница, цифры, «_» и «-» |
| `400 k must be an integer from 1 to 100` | Параметр `k` вне диапазона |
| `401 invalid or missing API key` | Начислять очки может только игровой сервер с ключом `X-API-Key` |
| У меня столько же очков, как у соседа, но я ниже | При равенстве очков выше тот, кто набрал их раньше |
| Мои очки пропали | Скорее всего, начался новый сезон. Прошлые результаты хранятся в архиве |
