**Студент:** Карпач В.Р.
## Постановка

Таблица лидеров. User: как попадают очки, как смотреть топ. Tech: модель игрока. OpenAPI: обновить счёт, топ-K, игрок по нику, сброс сезона (описать осторожно).

## Обзор проекта

Сервис хранит очки игроков в рамках сезона и отдаёт таблицу лидеров. Игровой сервер начисляет очки, клиенты читают топ и позицию игрока, администратор может сбросить сезон. API описано в формате OpenAPI 3.0.3 (6 операций), есть минимальная stub-реализация на Python без зависимостей.

## Как посмотреть спецификацию

1. **Swagger UI локально:** `python src/server.py`, затем открыть `http://localhost:8000/docs`. Запросы можно выполнять прямо в интерфейсе (нужен интернет для загрузки Swagger UI с CDN).
2. **Без запуска кода:** вставить содержимое `openapi.yaml` в [Swagger Editor](https://editor.swagger.io).

Ключи для локального запуска по умолчанию: `X-API-Key: dev-api-key` (начисление очков), `X-Admin-Token: dev-admin-token` (сброс сезона). Подробности в [tech.md](docs/tech.md).

## Операции API

| Метод и путь | Назначение |
|--------------|-----------|
| `POST /scores` | начислить очки игроку (ключ игрового сервера) |
| `GET /leaderboard?k=` | топ-K игроков |
| `GET /players/{nickname}` | игрок по нику: очки и место |
| `GET /season` | текущий сезон |
| `POST /season/reset` | сброс сезона (администратор, с подтверждением) |
| `GET /health` | проверка доступности |
